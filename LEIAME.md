# Recursos do Pokémon Simulator Evolution

Esta branch guarda a pasta `recursos/` (sprites, mapas, itens e músicas) em arquivos `.zip`.
O workflow de release (`.github/workflows/release.yml`, na `main`) lê estes arquivos para montar o pacote completo do jogo.
Cada `.zip` contém a pasta `recursos/` dentro; para atualizar, troque os arquivos e envie para esta branch.
